# Zev Portfolio — GitHub Pages

This folder is ready to publish with GitHub Pages.

## Structure
- `index.html` — working portfolio homepage / flagship case study

## Publish
1. Create a GitHub repository.
2. Upload the contents of this folder.
3. In GitHub: Settings → Pages.
4. Set deployment source to the repository branch/root.
5. GitHub will publish the site.

## Working rule
The GitHub Pages site is the primary portfolio artifact.
The LuggAgent Miro board is source material only and should not be modified for Zev's personal portfolio.
